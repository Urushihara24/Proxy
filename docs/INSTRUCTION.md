# Customer Guide (Windows)

## 1) Download the application

Download the release archive:

- [Proxy-Seller-Launcher-Windows-v1.0.0.zip](https://github.com/Urushihara24/Proxy/releases/download/v1.0.0/Proxy-Seller-Launcher-Windows-v1.0.0.zip)

## 2) Extract the archive

Extract the `zip` file into any convenient directory, for example:

- `Desktop\Proxy Seller Launcher`

Important:

- Do not run the `.exe` directly from inside the archive.
- The `_internal` directory must remain next to `Proxy Seller Launcher.exe`.

## 3) Start the application

Run:

- `Proxy Seller Launcher.exe`

If Windows SmartScreen appears:

1. Click `More info`.
2. Click `Run anyway`.

## 4) First launch and normal use

1. Paste your Proxy-Seller API key.
2. Press `Обновить данные`.
3. Select the proxy type and parameters: country/period or tariff.
4. Press:
   - `Подключить купленный` if the proxy has already been purchased, or
   - `Купить и подключить` to create a new paid order.

> The application UI is currently Russian, so button labels are kept exactly as they appear in the application.

## 5) Useful controls

- `Отключить прокси` — disable the system proxy.
- `Ещё -> Показать активные` — show active proxies.
- `Ещё -> Проверить баланс` — check the account balance.
- `Ещё -> Подключить последний` — quickly reconnect the last working proxy.

## 6) If the application does not start

1. Make sure the archive was fully extracted.
2. Run `Proxy Seller Launcher.exe` again.
3. Check whether SmartScreen or antivirus software blocked the launch.
4. Restart Windows and try again.

If the problem remains, send the developer:

- a screenshot of the error,
- your Windows version,
- the step at which the error occurs.
